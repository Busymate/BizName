# Changelog

All notable changes to BizName are documented here. This file is
maintained by hand alongside `src/config/version.js` — when you bump
`APP_VERSION`, add a matching entry here and to `RELEASE_HISTORY`.

BizName uses [Semantic Versioning](https://semver.org/):
- **PATCH** (1.0.x) — bug fixes
- **MINOR** (1.x.0) — new features, backwards compatible
- **MAJOR** (x.0.0) — redesigns, breaking changes, major AI upgrades
